**App Shell (6.15)**: the workspace picker on `/` is gone. It was a development
shortcut from before roles were resolved server-side; `/` now forwards each
signed-in user to their own dashboard by role, and anonymous visitors to
`/login`. See [Where people land](/docs/invitations-onboarding#where-people-land).

**Super-Admin (6.11)**: the Week 4 invite-new-WP action is wired — the dialog creates a real invitation, and `/admin` is gated to `super_admin`. The rest of the Week 4 pass (impersonation procedures, feature-flag toggles, the wired WP list actions) is still open.

**Transactional Email Integration (6.14)** stays *in-progress* on purpose. Its first step — the send helper and `consoleDriver` — shipped with onboarding, and every mail path in the app already runs through it. What remains is the provider account, the sender domain and DKIM record, and `providerDriver` itself, which needs credentials that do not exist yet. See [Invitations and Onboarding](/docs/invitations-onboarding#the-email-layer).

## Known deviation from the kickoff runbook

The runbook (and this repo's `bfa-requirements` skill / compliance checks) refer to the docs app as `apps/docs`. Better-T-Stack actually scaffolded it as **`apps/fumadocs`** (package name `fumadocs`). All documentation-path references in this repo use the real path — `apps/fumadocs/content/docs` — not `apps/docs`.

## Open questions blocking phase completion

Carried from [PRD § 10](/docs/prd#10-open-questions-for-the-client) — resolve before the owning phase is marked done:

- **Phase 2:** WPAdmin/WPsubAdmin/WPEmployee permission differences — all three currently share identical invitation policies; second-WP-invite notification behavior.
- **Phase 3:** signature vs. certify-checkbox; legacy PDF/results-document layout match (reference wizard: [bfr-temi-wiz-final.bubbleapps.io](https://bfr-temi-wiz-final.bubbleapps.io/version-test/wizard)).
- **Phase 4:** whether a WP can reassign the BIN itself on an existing asset (vs. one-time assignment only).
- **Phase 5:** dynamic variables for notice text; AG Renewal Date auto-update behavior; monthly CSV export field list.

Resolved since the last pass (no longer blocking): mid-wizard pass/fail handling, scope of "edit submitted test data" for a WP, asset↔customer cardinality, email routing for suspended customers — see [PRD § 9](/docs/prd#9-confirmed-decisions-client-qa-log).
